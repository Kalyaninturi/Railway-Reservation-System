RAILWAY RESERVATION SYSTEM - ECLIPSE PROJECT

Import:
1. Extract this ZIP.
2. Open Eclipse > File > Import.
3. Select General > Existing Projects into Workspace > Next.
4. Browse to the extracted RailwayReservationSystem folder.
5. Select the project and click Finish.
6. Expand src > railwayreservation.
7. Right-click Main.java > Run As > Java Application.

Default user: user1 / user123
Admin: admin / admin123

Data files are saved in a local data folder. This is a beginner demo; passwords are stored as plain text locally.
